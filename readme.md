# Broad Software Engineering Retreat 2025

This repository contains the information and resources on Nix presented in the Broad Software Engineering Retreat 2025.

## Resources
### First steps
- [Install nix](https://nixos.org/download/): Nix Installation
- [Declarative shell environments with shell.nix](https://nix.dev/tutorials/first-steps/declarative-shell): The very fist early steps
- [Simple start with Nix Home Manager and flakes](https://github.com/Evertras/simple-homemanager): Approachable step-by-step introduction to home-manager and flakes (self-contained and fully reproducible Nix declarations). 
- [Nix search](https://search.nixos.org/packages): Search your packages of interest on nixpkgs.
- [Official Nix documentation](https://nix.dev/): Official Nix Documentation
- [Nix Darwin](https://github.com/nix-darwin/nix-darwin#getting-started): Nix on your MacOS.


### Other useful resources
- [NixOS manual](https://nixos.org/manual/nixos/stable/): In-depth details of NixOS and its components.
- [Nixpkgs reference manual](https://nixos.org/manual/nixpkgs/stable/): In-depth details of Nixpkgs.
- [nix pills](https://nixos.org/guides/nix-pills/01-why-you-should-give-it-a-try.html): Complement of the manual with examples to try out.
- [nix-ld](https://github.com/nix-community/nix-ld): Run unpatched dynamic binaries on NixOS
- [Awesome nix](https://github.com/nix-community/awesome-nix): Collection of cool nix-related projects.
- [Home-manager manual](https://nix-community.github.io/home-manager/): In-depth 
- [nixpkgs](https://github.com/NixOS/nixpkgs):  Nix Packages collection & NixOS 

## Repository structure
This repository produces both the poster and slides using emacs org-mode and latex (all the dependencies defined in a flake).
